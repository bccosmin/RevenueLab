# RevenueLab — Agent Collaboration Workflows

## 1. Purpose

This document defines how specialized RevenueLab agents collaborate to execute end-to-end B2B sales workflows.

The objective is to create a coordinated intelligence system in which each agent contributes specialized expertise while working toward a shared commercial outcome.

The Sales Orchestrator owns workflow coordination, task delegation, output validation and final synthesis.

## 2. Collaboration Principles

All agent workflows must follow these principles:

- One clearly defined commercial objective.
- Explicit ownership of each task.
- Shared and consistent context.
- Structured information handoffs.
- Evidence-based conclusions.
- Clear distinction between facts and hypotheses.
- No unnecessary agent activation.
- Human oversight of consequential decisions.

Agents must not operate as disconnected assistants producing unrelated recommendations.

## 3. Standard Agent Handoff Protocol

Every agent-to-agent handoff should contain:

### Task Context
What is the commercial objective?

### Source Context
What information is available and where did it originate?

### Previous Findings
What has already been established?

### Evidence Classification
Which findings are verified, inferred, hypothetical or unknown?

### Assigned Task
What exactly must the receiving agent accomplish?

### Expected Output
What information or recommendation should it return?

### Open Questions
What remains unresolved?

The receiving agent must preserve relevant context and must not reinterpret hypotheses as verified facts.

## 4. Workflow A — Account Intelligence

**Objective:** Understand and prioritize potential target accounts.

### Execution Sequence

1. Sales Orchestrator receives the target market, ICP or account list.
2. Research Agent investigates relevant companies.
3. Research Agent returns structured company intelligence.
4. Prospecting Agent evaluates ICP alignment.
5. Prospecting Agent identifies potential buying signals.
6. Prospecting Agent develops opportunity hypotheses.
7. Sales Orchestrator reviews and consolidates findings.

### Final Deliverable

- Account overview.
- ICP fit assessment.
- Relevant business context.
- Buying signals.
- Potential business challenges.
- Opportunity hypotheses.
- Account priority.
- Recommended outreach angle.

### Success Criteria

The workflow must help the sales professional understand which accounts deserve attention and why.
